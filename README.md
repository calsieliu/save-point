# SAVE POINT

A Salomon × Paris city survival game concept for Gen Z, set in summer 2028: four weeks, three district levels, a photo-booth "save" after each level, and a final stage at Les Halles.

Student project by TZU-HSUAN LIU, Grenoble Ecole de Management (MSc Fashion, Design & Luxury Management · Futuretopia 2028). Not an official event or Salomon campaign.

Live site: https://calsieliu.github.io/save-point/
